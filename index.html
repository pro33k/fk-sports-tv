🚀 GitHub Free Hosting Setup

Your admin panel and channels file are hosted free on GitHub Pages:

Step 1: Edit here

Add, edit or switch off channels. The panel loads the live channels.json from GitHub when it opens.

Step 2: Export channels.json

Click "Export channels.json" and upload it to the root of your repo, replacing the old file. Your app reads it from:

https://pro33k.github.io/fk-sports-tv/channels.json

Step 3: Admin page link

This panel is served from index.html at:

https://pro33k.github.io/fk-sports-tv/

GitHub Pages can take 1–2 minutes to update after you upload. Anyone with the link can open this panel, but changes only reach your app after you upload channels.json.
